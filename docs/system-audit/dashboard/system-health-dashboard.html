🔥 Top 5 Critical Engineering Risks

Immediate architectural threats requiring pre-launch resolution

1. Cross-Section Referral IDOR Tampering SEC-01

Authenticated employees can overwrite, re-route, or alter referral actions of any document in any department due to missing ownership authorization.

2. Sequence Collisions in Tracking Numbers CONC-01

Concurrent document submissions compute duplicate tracking numbers via Document::max() + 1, resulting in transaction rollbacks.

3. Zombie Sessions for Deactivated Accounts SEC-03

Deactivated staff remain fully operational because sessions are file-based and the auth layer never validates active status on subsequent requests.

4. Exponential N+1 Query Cascades on Dashboards PERF-01

Global $appends on Document executes dynamic tracking history lookups per row, taking 5+ seconds over Tokyo network connections.

5. Sequential Scan CPU Saturation PERF-02

Complex 6-branch OR visibility filters bypass PostgreSQL index trees, causing full sequential table scans that will bottleneck as table grows.
